# OpenAI-Free-Credit-Tracker

Track OpenAI free credits, usage, token costs, and model pricing in a simple dashboard.

## Features

- Track remaining free credits
- Monitor API usage costs
- Model pricing reference
- Token usage statistics
- Interactive charts and dashboard
- OpenAI API integration
